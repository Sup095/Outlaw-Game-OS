What is the System Core?

The System Core is your machine's status centre and assistant. The rings show live CPU, RAM and VRAM use. The badge shows the current VRAM-saver tier (change it in Settings → AI / VRAM).

Cold mode (default) uses built-in dialogue and sends zero AI traffic — fully offline and free. Go Live connects to your local LM Studio so the Core can answer questions and run safe actions for you (open an app, run a diagnostic, search files). Live mode only works when LM Studio is running with a model loaded.

Use the controls here to run a system diagnostic, watch temperatures, toggle performance mode, and talk to the Core. Nothing leaves your machine.

Task Manager

What is this?

A live view of everything running. The bars show CPU, memory and GPU / VRAM use. Click a row to select a process, then End task (asks it to close nicely) or End process tree (force-closes it and everything it started). Click a column heading to sort. The list refreshes every couple of seconds while you're on this screen. Some processes belong to the administrator and show needs admin when you try to end them — that's expected.

Secure Terminal

guarded
How does the terminal work?

A normal shell — type a command and press Enter; output appears above. It runs in your home folder as you. Destructive commands (like rm -rf, dd, mkfs) are intercepted and need you to type CONFIRM first, so you can't wipe the machine by accident. Use sudo for admin tasks; pacman for packages (or just use the Apps page).

AI Assistant

How does the AI work?

Outlaw runs AI privately on this PC — no internet, no account, nothing leaves the machine. It talks to LM Studio (a free local model runner). Click Check my PC below and Outlaw picks a model your hardware can actually run, then walks you through installing it. Weak PC? There's a tiny model that runs on almost anything — once it's loaded it can answer the rest of your setup questions itself.

Session graphics profile

What is this?

Installs the gaming/desktop graphics stack for your GPU — Vulkan, Mesa and the 32-bit libraries Steam & Proton need, plus GameMode and MangoHUD. It's userspace only: it never changes kernel drivers, the boot loader or your display mode, so it can't stop the machine booting. Use lean for dev/planning. Applied after boot via the package manager, and fully revertible. (NVIDIA: this installs the userspace libraries only — the NVIDIA kernel driver touches the boot path and isn't installed automatically.)
